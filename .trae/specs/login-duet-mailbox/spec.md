# 登录系统与双人信箱 - Product Requirement Document

## Overview
- **Summary**: 为信笺应用增加用户注册登录系统，支持两个预设账号，实现双人共享信箱功能，让两个用户可以在同一个信箱中互动游玩。
- **Purpose**: 提供用户身份识别能力，支持双人共享信箱体验，增强互动性和沉浸感。
- **Target Users**: 双人用户（情侣、朋友、家人等），希望共享一个信箱进行书信互动

## Goals
- 用户可以注册新账号
- 用户可以使用账号密码登录
- 预置两个测试账号可直接使用
- 两个账号可以关联到同一个共享信箱
- 登录后进入共享信箱，双方可看到彼此的信件
- 支持用户切换账号
- 保持原有单用户体验作为访客模式

## Non-Goals (Out of Scope)
- 不做后端服务，所有数据存储在 localStorage / IndexedDB（纯前端）
- 不做密码找回功能
- 不做账号安全验证（邮箱/手机验证）
- 不做多设备数据同步
- 不做实时通信/即时消息

## Background & Context
- 当前项目是纯前端应用，数据存储在 localStorage 和 IndexedDB
- 现有信箱系统支持多信箱、多信件
- 已有地图模式和角色系统，支持双人动作
- 技术栈：原生 JavaScript + HTML + CSS，无框架

## Functional Requirements
- **FR-1**: 登录页面 - 显示登录表单，支持账号密码输入
- **FR-2**: 注册功能 - 新用户可以注册账号
- **FR-3**: 预设账号 - 预置两个测试账号（修璟、萱宣）
- **FR-4**: 双人信箱关联 - 两个账号关联到同一个共享信箱
- **FR-5**: 登录状态保持 - 刷新页面后保持登录状态
- **FR-6**: 退出登录 - 用户可以退出登录返回登录页
- **FR-7**: 账号切换 - 支持在两个预设账号间切换
- **FR-8**: 共享信件 - 两个账号都能看到共享信箱中的所有信件
- **FR-9**: 写信人标识 - 信件显示发送者（哪个账号写的）
- **FR-10**: 访客模式 - 未登录时可继续使用原有的单用户体验

## Non-Functional Requirements
- **NFR-1**: 登录/注册操作响应时间 < 300ms
- **NFR-2**: 登录页面 UI 风格与现有应用一致（古风/书信主题）
- **NFR-3**: 移动端适配良好
- **NFR-4**: 密码使用哈希存储，不明文保存
- **NFR-5**: 不影响现有功能的正常使用

## Constraints
- **Technical**: 纯前端实现，无后端服务；使用 localStorage 存储用户数据
- **Business**: 两个预设账号固定为修璟（男）和萱宣（女）
- **Dependencies**: 依赖现有 storage.js 存储模块

## Assumptions
- 用户在同一设备上使用两个账号（本地存储）
- 双人信箱是一个共享空间，双方都可以读写
- 信件的"作者"字段用于区分是谁写的
- 用户可以随时切换账号体验不同视角

## Acceptance Criteria

### AC-1: 登录页面显示
- **Given**: 用户打开应用
- **When**: 用户未登录
- **Then**: 显示登录页面，包含账号输入框、密码输入框、登录按钮、注册入口
- **Verification**: `human-judgment`
- **Notes**: UI 风格应与信笺应用整体风格一致

### AC-2: 用户注册
- **Given**: 用户在登录页面
- **When**: 用户点击"注册"，填写用户名和密码并提交
- **Then**: 账号创建成功，自动登录并进入应用
- **Verification**: `programmatic`
- **Notes**: 用户名不能重复，密码不能为空

### AC-3: 用户登录
- **Given**: 用户已注册账号
- **When**: 用户输入正确的账号密码并点击登录
- **Then**: 登录成功，进入应用主页
- **Verification**: `programmatic`

### AC-4: 登录失败提示
- **Given**: 用户在登录页面
- **When**: 用户输入错误的账号或密码
- **Then**: 显示错误提示信息
- **Verification**: `programmatic`

### AC-5: 预设账号可用
- **Given**: 应用首次启动
- **When**: 用户尝试使用预设账号（修璟/萱宣）登录
- **Then**: 可以成功登录
- **Verification**: `programmatic`
- **Notes**: 预设账号密码简单易记，如 123456

### AC-6: 登录状态保持
- **Given**: 用户已登录
- **When**: 用户刷新页面
- **Then**: 仍保持登录状态，不需要重新登录
- **Verification**: `programmatic`

### AC-7: 双人共享信箱
- **Given**: 两个账号（修璟、萱宣）已关联到同一个共享信箱
- **When**: 修璟写了一封信
- **Then**: 萱宣登录后可以看到这封信
- **Verification**: `programmatic`

### AC-8: 信件作者标识
- **Given**: 共享信箱中有多封来自不同用户的信件
- **When**: 用户查看信件列表
- **Then**: 可以区分每封信是谁写的
- **Verification**: `human-judgment`

### AC-9: 退出登录
- **Given**: 用户已登录
- **When**: 用户点击退出登录
- **Then**: 返回到登录页面，登录状态清除
- **Verification**: `programmatic`

### AC-10: 访客模式
- **Given**: 用户未登录
- **When**: 用户点击"访客模式"或"随便看看"
- **Then**: 可以进入应用，使用原有的单用户数据
- **Verification**: `human-judgment`
