# Bing 真实信件参考升级说明

Figma 文件：<https://www.figma.com/design/5O05AZHQOEO8jr1YqNg3zm>

本次新增画板：`08 / Bing reference realism upgrade`

## 设计目标

这版不再把信件做成干净图标或平面模板，而是按真实图片里的信件实物重新拆解：

- 纸张层：发黄、折痕、破角、污渍、纸纤维、边缘叠层。
- 邮政层：邮票、邮戳、销票波纹、编号、地址线、航邮红蓝边、收发章。
- 内容层：高密度手写、竖排栏线、墨色深浅、票据式表格。
- 场景层：桌面、布面、木纹、扫描床、实物阴影、倾斜视角。

## 新增 8 个高真实度模板方向

1. 旧邮戳信封叠件：多封旧信封叠放、圆形邮戳、销票波纹、发黄破角。
2. 航邮蓝红边封：PAR AVION 标签、红蓝斜边、邮票区、地址线和圆戳压线。
3. 中式牛皮纸信封：红框地址栏、竖排题签、牛皮纸厚度、收寄章。
4. 电报 / 急件纸：表格、编号、STOP 断句、急件红章、旧纸扫描感。
5. 侨批红带封套：成叠纸边、红色束带、竖写姓名、汇款与侨批语义。
6. 旧票据批信：红栏表格、印章覆盖、脆纸、双联票据扫描感。
7. 竖排家书相片款：红色竖线、旧照片、航邮边、桌面道具和花饰。
8. 现代邮件 / 信箱材质：快递标签、条码、透明窗口、铁皮/木盒信箱材质。

## 落地建议

在真实生成器里把每个模板拆成可开关图层：

- `paper_texture`
- `fold_marks`
- `postal_marks`
- `handwriting_density`
- `desk_shadow`
- `photo_props`
- `mailbox_material`

导出时优先生成「完整信件实物图」，而不是单独信纸背景。这样才能接近 Bing 图片里看到的真实信件质感。
