Implementation Rules

下一步可落地到项目里的 CSS 规则

这些规则可以从本页拆出为模板系统：模板只保存类型、颜色、文字方向和材质强度，视觉由 CSS 生成。

纸张层使用多重 radial-gradient 和 repeating-linear-gradient 做纤维、黄斑、压痕、水渍。
结构层信封使用 flap、seam、stamp、postmark、address-lines；信纸使用 red-rules、blue-rules、seal。
文字层按模板切换 writing-mode、字体族、字号、行高、墨色和轻微旋转。
交互层卡片点击切换预览，按钮保持 44px 以上，减少纯 hover 依赖。
