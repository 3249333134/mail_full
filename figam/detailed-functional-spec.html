Detailed Functional Specification

信笺 · 详细功能规格与操作逻辑说明书

本文档对产品各功能模块的操作流程、状态流转、边界情况与交互细节进行详细定义，作为开发实现与测试验收的依据。

一、信箱管理系统

信箱创建

MB-001 · P0
功能入口首页「+ 新建信箱」按钮 / 信箱总览页右上角
触发方式点击按钮弹出创建表单
前置条件无，首次使用引导创建

操作流程

  1. 用户点击「新建信箱」按钮，从右侧滑出创建面板（抽屉式，宽度 360px）
  2. 填写信箱名称（必填，2-20字，实时校验字数）
  3. 选择信箱图标：提供 12 个预设图标（信封、邮筒、心形、星星、书本、礼物等），默认信封
  4. 选择主题色：6 色可选（玫瑰红、墨蓝、墨绿、暖金、深紫、炭灰），默认玫瑰红
  5. 填写信箱描述（选填，最多 50 字，显示在信箱卡片副标题）
  6. 选择默认信纸样式：下拉选择，默认「暖白信纸」
  7. 点击「创建」按钮，面板收起，新信箱出现在列表最前面，有淡入动画
  8. 创建成功后顶部出现 Toast 提示「信箱创建成功」，持续 2 秒

字段规则

字段规则校验时机错误提示
信箱名称必填，2-20字符，不可全为空格失焦 + 提交时名称不能为空 / 名称不能超过20字
信箱描述选填，最多50字符输入时实时计数超出时禁止继续输入
重名校验同一用户下信箱名称不可重复提交时该信箱名称已存在
边界情况 信箱数量无上限，但超过 20 个时在创建时轻提示「信箱较多，建议整理归档」，不强制限制。

信箱编辑与删除

MB-002 · P0
功能入口信箱卡片右键菜单 / 信箱设置页
触发方式右键 / 点击设置图标
前置条件信箱已存在

编辑操作流程

  1. 在信箱卡片上悬停，右上角出现「···」更多按钮
  2. 点击展开下拉菜单：编辑信箱、信箱设置、删除信箱
  3. 选择「编辑信箱」，弹出与创建相同的表单，预填充当前数据
  4. 修改后点击「保存」，实时更新信箱卡片外观

删除操作流程

  1. 选择「删除信箱」，弹出确认对话框
  2. 对话框显示：信箱名称、信件数量、警告文案「删除后所有信件将一并移除」
  3. 提供两种选项：移入回收站（保留7天）、立即彻底删除
  4. 默认选中「移入回收站」，用户确认后执行
  5. 彻底删除需二次确认：输入信箱名称后才可点击删除
  6. 删除后信箱从列表消失，出现撤销 Toast（5秒内可撤销）
边界情况 最后一个信箱不可删除，删除按钮置灰并提示「至少保留一个信箱」。回收站中的信箱可在「设置 - 回收站」中恢复或清空。

信件堆叠浏览

MB-005 · P1
功能入口信箱详情页主区域
触发方式进入信箱自动加载
交互方式点击 / 拖拽 / 键盘 / 滚轮

操作流程

  1. 进入信箱详情，信件以层叠卡片形式展示，当前信件居中放大（100%）
  2. 前后各露出 1-2 封信的侧边（约 15% 宽度），有透明度渐变
  3. 切换方式一：点击左右两侧露出的信件，切换到对应信件
  4. 切换方式二：拖拽当前卡片向左/右，松手后吸附到目标位置
  5. 切换方式三：键盘左右方向键切换（信箱页面聚焦时生效）
  6. 切换方式四：鼠标滚轮横向滚动切换
  7. 切换动画：卡片位移 + 缩放 + 透明度变化，时长 300ms，ease-out
  8. 点击当前卡片中央区域 → 进入阅读器（触发拆信动画）

卡片信息展示

元素展示规则位置
信封外观继承信箱主题色，显示信纸一角露出卡片主体
信件标题居中显示，无标题时显示「无题」信封正面中部
日期格式：YYYY年M月D日信封右下角
未读标记红色蜡封点，未读时显示信封封盖处
附件标记有录音显示声波图标，有照片显示相机图标信封左下角
性能优化 超过 50 封信时采用虚拟渲染，只渲染当前及前后各 2 封，滚动时动态加载。首屏只加载最近 20 封的元数据。

装饰元素分类

分类可选样式说明

操作逻辑

  1. 进入信箱设置的「装饰外观」标签页
  2. 左侧为实时预览区，显示当前装饰组合效果

  4. 点击任一选项，左侧预览实时更新（150ms 过渡动画）
  5. 底部提供「随机组合」按钮，一键随机生成装饰搭配
  6. 点击「保存」应用设置，点击「重置」恢复默认

二、信件编辑器

三栏布局结构

ED-001 · P0

布局规则

区域宽度最小宽度可折叠内容
左侧工具轨64px（收起）/ 220px（展开）64px是页面缩略图、基础工具、组件库
中间画布区自适应剩余空间400px否信纸画布 + 顶部工具栏
右侧属性面板280px240px是选中元素属性、信纸设置

左侧工具轨详细结构

  1. 顶部：页面缩略图区 — 垂直排列每页缩略图，当前页高亮。底部「+」按钮新增页面。拖拽可调整页面顺序。右键菜单：复制页、删除页、移动到。
  2. 中部：基础工具组 — 6个图标按钮：文字(T)、图片、录音、视频、贴图、组件。点击后在画布上点击/拖拽创建对应元素。
  3. 底部：组件库 — 点击展开组件面板，包含：日期组件、收信人、地点标签、年度计划、月计划、周计划、日计划、清单。拖拽到画布插入。

中间画布区交互

  1. 信纸画布居中显示，有阴影和轻微透视感
  2. 顶部工具栏：当前样式名称（点击切换样式）、缩放百分比下拉、适应宽度按钮、网格开关
  3. 画布支持：拖拽移动元素、双击编辑文字、滚轮缩放画布、空格拖拽平移
  4. 选中元素时出现 8 个调整手柄 + 旋转手柄

右侧属性面板分段

  1. 信纸/封面切换 — 顶部 Tab，切换编辑信纸正面或信封封面
  2. 元素属性区 — 无选中时显示信纸属性（样式、纸张、背景）；选中元素时显示对应属性
  3. 层级与对齐 — 置顶/置底/上移/下移 + 6种对齐方式
  4. 定时寄出 — 折叠区，设置发送时间和目标信箱
  5. 草稿与版本 — 显示最后保存时间，查看历史版本
响应式规则 窗口宽度 < 1024px 时，左右面板自动收起为图标条，点击展开浮层。< 768px 时改为底部工具栏 + 全屏画布。

语音录制

ED-007 · P0

录制流程

  1. 点击左侧录音工具 → 画布中央出现录音面板
  2. 首次使用触发麦克风权限请求，浏览器原生弹窗
  3. 权限允许后：显示波形动画 + 录制时长计时 + 红色录制指示灯

语音气泡属性

属性选项说明
气泡样式简约线框 / 纸质便签 / 磁带造型不同的视觉表现
气泡颜色跟随主题色 / 自定义默认玫瑰色

技术参数

  • 格式：WebM（Chrome/Edge）/ M4A（Safari），自动适配
  • 采样率：44.1kHz

撤销 / 重做栈

ED-009 · P0

入栈规则

操作类型入栈时机命令粒度
新增元素元素创建完成时单条命令
删除元素确认删除时单条命令
移动元素拖拽结束（mouseup）时整个拖拽算一次
缩放/旋转拖拽结束时整个调整算一次
属性修改属性值确认后（失焦/滑块释放）同类连续操作合并
文字输入停止输入 1 秒后或换行时连续输入合并为一条
多元素批量操作操作完成时批量操作算一条命令

栈规则

  • 最大历史步数：50 步
  • 超出 50 步时，最早的记录被丢弃（FIFO）
  • 撤销后执行新操作 → 重做栈被清空（分支丢弃）
  • 操作栈随草稿自动保存，刷新页面后可继续撤销
  • 快捷键：Ctrl+Z 撤销，Ctrl+Shift+Z / Ctrl+Y 重做
命令模式实现 每个操作封装为 Command 对象，包含 execute() 和 undo() 方法。移动/缩放等连续操作使用节流合并，避免每像素入栈。

辅助线与吸附对齐

ED-011 · P0

吸附触发规则

吸附类型触发条件视觉反馈
左边缘对齐当前元素左边与其他元素左边距离 ≤ 8px红色垂直辅助线
右边缘对齐当前元素右边与其他元素右边距离 ≤ 8px红色垂直辅助线
水平中心对齐两元素水平中心线距离 ≤ 8px红色垂直虚线
顶部对齐两元素顶部距离 ≤ 8px红色水平辅助线
底部对齐两元素底部距离 ≤ 8px红色水平辅助线
垂直中心对齐两元素垂直中心线距离 ≤ 8px红色水平虚线
等间距分布三个以上元素间距接近相等时双向箭头间距标识

操作细节

  1. 拖拽元素移动过程中实时计算与其他元素的位置关系
  2. 距离小于 8px 阈值时触发吸附，元素跳转到精确对齐位置
  3. 吸附后继续拖拽需先「挣脱」吸附区（移动超过 8px）才恢复自由拖拽
  4. 辅助线为 1px 实线，颜色 #c96567，带轻微发光效果
  5. 按住 Alt 拖拽时临时禁用吸附
  6. 顶部工具栏有「吸附对齐」开关，可全局关闭

三、信件阅读器

拆信动画完整流程

RD-001~003 · P1

动画分阶段时序

阶段时长动画内容音效
阶段一：蜡封裂开0.2s蜡封中心出现裂纹，向两侧延伸分叉，蜡块分两半微位移轻微「咔」声（0.1s）
阶段二：蜡封滑落0.25s两半蜡封向左右两侧滑落并轻微旋转，带重力加速度下落感「嗒」轻响（落地声）
阶段三：信封翻盖0.35s上盖沿顶部边缘向上翻开，角度从 0° → 110°，透视变形纸张摩擦声（0.3s）
阶段四：信纸抽出0.4s信纸从信封中向上滑出，同时信封向后退并缩小淡出纸张抽出声（0.3s）
阶段五：聚焦展开0.3s信纸放大到阅读尺寸，背景柔和变暗，操作栏淡入无

总时长约 1.5 秒，阶段间有重叠过渡，非严格串行。

跳过与重看机制

  • 同一封信首次打开：完整播放拆信动画
  • 同一封信第二次及以后打开：直接进入阅读态，跳过动画
  • 阅读中点击「重新拆信」按钮：可重新播放一次拆信动画
  • 设置中「始终播放拆信动画」开关：开启后每次都完整播放
  • 动画播放中点击任意位置：跳过剩余动画，直接显示信件
音效策略 所有拆信音效在用户首次交互（点击）后才加载播放，规避浏览器自动播放限制。首次打开时静音播放动画，用户点击后后续信件带音效。

信件状态流转

状态触发条件用户可见可操作
草稿新建信件未设置定时编辑器中编辑、删除
待寄出设置了定时时间且未到待寄列表 + 信箱中灰色显示修改时间、取消定时、撤回编辑

自动送达机制

  • 应用运行时：每分钟检查一次待寄列表，到达时间的信件自动标记已送达
  • 应用关闭时：下次启动时批量检查，所有到期信件统一「派件」
  • 离线期间到期的：下次打开时播放「新信到达」动画 + 提示音
  • 使用本地通知（Notification API）：到期时如应用在后台，发送系统通知
时间准确性 基于本地系统时间，不依赖服务器。用户修改系统时间可能影响送达，但符合本地优先设计原则。撤回窗口（10分钟）是为了模拟「信件还在邮筒里可以拿回来」的真实感。

随机慢递模式

SD-005 ~ 007 · P2

三种慢递档位

模式随机范围预计到达进度显示
平邮3 - 7 天约一周内显示「已寄出 X 天，预计还需 Y 天」
慢递30 - 90 天（1-3个月）1-3个月内随机显示月份范围，不显示具体日期
半年期90 - 180 天（3-6个月）半年内某个时刻只显示「投递中…」，不显示预计时间

随机算法规则

  • 寄出时根据选择的模式生成一个随机天数（整数）
  • 随机数生成后固定，不再变化
  • 分布策略：正态分布偏中间值，避免总是最短或最长
  • 用户看不到具体日期，只看到范围或模糊描述
  • 「惊喜感」设计：半年期模式完全不显示进度，用户不知道哪天会到

投递中状态视觉

  1. 信箱中出现一个「在路上」的信封：半透明、倾斜角度、有邮戳
  2. 悬停显示预计到达范围（平邮/慢递模式）
  3. 待寄列表中显示：模式标签、寄出时间、预计范围、进度条（平邮显示精确进度，慢递显示模糊进度）
  4. 到达当天：信箱出现「新信」动画 + 红色未读标记

加密投递包（离线交换）

SD-009 · P2

导出投递包流程

  1. 写完信后选择「生成投递包」
  2. 设置收件密码（4-16位），对方导入时需输入
  3. 可选：设置延迟打开时间（对方收到后也需等到时间才能拆信）
  4. 生成 .letter 后缀的加密文件（AES-256 加密）
  5. 文件包含：信件内容、所有媒体资源、元信息
  6. 用户手动通过任何渠道发送给对方（微信/邮件/U盘等）

  1. 首页「导入投递包」入口，选择 .letter 文件
  2. 弹出密码输入框，输入收件密码
  3. 密码正确 → 预览信件摘要（寄件人、日期、是否定时）
  4. 选择目标信箱 → 确认导入
  5. 如设置了延迟打开：信件进入待寄状态，到时间才可阅读
  6. 未设置延迟：直接出现在信箱中，可立即拆信阅读
无后端设计 投递包是本地优先架构下的「离线信件交换」方案。应用本身不提供传输通道，用户使用自己的通信方式传递文件，应用只负责加密打包和解密读取。

  • 导入过程中任何步骤失败 → 自动回滚到导入前状态
  • 回滚完成后显示错误原因和建议
  • 不会出现「导入了一半」的脏数据状态
版本兼容 备份文件带有应用版本号。导入旧版本备份时自动执行数据迁移脚本；导入新版本备份时提示「备份来自更高版本，可能无法完整导入，建议升级应用」。
