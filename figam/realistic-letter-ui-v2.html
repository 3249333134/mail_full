UI/UX Pro Max Translation

把信纸和信封做成“可触摸的实物系统”

这版不再把信件模板当作普通卡片，而是按真实书信照片重新拆层：桌面光线、纸张厚度、折痕破角、邮戳票据、手写密度、印章和封套结构都进入 UI 规则。用户看到的不是装饰图，而是一套可以选择、编辑、保存和导出的真实信件材质。

真实纸张纹理 毛笔 / 钢笔 / 打字机字体 信箱单元装饰 模板可点击切换 移动端全屏画布
打开原真实信件生成器 打开信箱装饰工作台 打开现有 HTML 总览
设计系统取向 复古档案感 + 真实摄影材质，减少纯扁平装饰，强化“纸在桌面上”的空间关系。
交互取向 模板选择、信箱设置和导出都保留 44px 以上触控目标，并提供清晰选中状态。
字体取向 标题用宋体/黑体稳住信息层级，信件正文按模板切换毛笔、楷体、仿宋、等宽像素风。
材质取向 信纸不只换底色，而是叠加纤维、压痕、边缘泛黄、折线、污渍、水渍和墨迹深浅。
这两张图作为 V2 的真实感标准 从单张背景纹理升级为“实物层级”：照片视角、纸张边缘、折痕阴影、邮政信息和手写痕迹共同构成模板。
