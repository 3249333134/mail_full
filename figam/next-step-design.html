Priority Matrix

  • 一键备份、导入恢复、加密导出

中优先级

  • 蜡封拆封动画与轻量音效

易用性

  • 首次使用引导和简洁模式
  • 移动端底部工具栏与属性抽屉

  • 大资源迁移到 IndexedDB
  • 数据库版本升级与迁移

Interaction Flows

关键 UI 与操作逻辑

01

拆信阅读与语音播放

解决自动播放失效，保留仪式感。

信

第十七封

拆信动画完成后，语音气泡从右下浮出。

  1. 用户点击信件卡片，开始蜡封裂开和翻盖动画。
  2. 动画结束后显示语音气泡，用户点击才播放录音。
  3. 若本会话已点击过 BGM/录音，则允许后续自动淡入播放。
  4. BGM 降到 15%，录音淡入；录音结束后 BGM 淡回。
02

编辑器基础能力补全

把丰富工具变成可靠的创作系统。

愿君安
属性
  1. 所有新增、删除、移动、属性修改进入 50 步操作栈。
  2. 拖拽时显示中心线、边距线，靠近后吸附。
  3. 右侧属性面板提供上移、下移、置顶、置底。
  4. 文字支持横排 / 竖排切换，适配复古与和风信纸。
03

备份恢复与自动草稿

给高情感价值内容一个安全感入口。

存在未完成的草稿

上次编辑于 23:42，包含 2 页信纸、1 段录音。

备份信笺 信箱、信件、手账、媒体
  1. 编辑器每 20-30 秒保存草稿，按 mailboxId 与 letterId 归档。
  2. 再次进入编辑页时优先弹出恢复提示。
  3. 备份导出 JSON；媒体可 base64 内嵌或独立资源包。
  4. 导入前展示备份内容摘要，防止误覆盖。
04

双人信箱与时光慢递

把等待设计成产品体验，而不是后台状态。

投递中 约 3 天后送达
新的来信 下次启动时自动送达
投递包 加密文件，可跨设备导入
  1. 寄出后进入“投递中”，按设置时间到达。
  2. 离线期间到达的信，下次启动补送达并提示。
  3. 随机慢递支持 1-3 个月、半年内、平邮模式。
  4. 双人信箱可导出加密投递包，无后端也能交换。
05

日记、手账与写信闭环

让支线内容成为主体验的记忆索引。

目录 1995 初遇 2000 雨夜 2005 仓库
书签

以撒的日记

写完信后，同步到今日手账。

  1. 日记增加目录、书签、页码定位。
  2. 写完信后可一键生成手账记录。
  3. 手账支持按关键词、日期、收信人搜索。
  4. 年/月/日/清单任务状态与信纸计划组件同步。
06

移动端编辑与简洁模式

把复杂功能收进手势和底部面板。

新建信件
愿君安
属性面板 字号 · 层级 · 对齐 · 透明度
简洁模式 隐藏手账、待寄、日记，仅保留收信与写信。
  1. 移动端编辑器改为全屏画布 + 底部工具栏。
  2. 属性面板从底部弹出，避免挤压画布。
  3. 画廊、日记支持左右滑；信纸支持双指缩放。
  4. 首次进入按模块触发新手引导，不一次性打扰。
