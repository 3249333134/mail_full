FUNCTIONAL SPEC TO UI

按详细功能规格拆出的逐级操作蓝图

基于 detailed-functional-spec.html，把每个模块从一级入口到四级弹窗/属性面板都设计成可落地的界面规则。用户每点一步，系统要给出状态、反馈、恢复路径。

全局原则

每个功能都遵循 5 段式交互

入口 选择 编辑 确认 反馈

入口要清晰，选择要可撤销，编辑要自动保存，确认要防误触，反馈要说明下一步。

页面分级

L1-L4 不混在同一层

L1全局入口：信箱、手账、待寄、搜索、设置 L2对象列表：信箱详情、待寄列表、搜索结果 L3核心任务：阅读器、编辑器、计划组件、日记页 L4局部面板：属性、装饰、定时、备份、权限提示
反馈状态

所有高价值内容都要可恢复

25s 草稿 3s 停顿保存 5 个历史版本 导入前快照 失败自动回滚
MB

信箱管理系统

创建、编辑、删除、堆叠浏览、信箱装饰。

L1 我的信箱

侧栏 + 首页网格显示所有信箱，提供新增、搜索、快速继续、备份入口。

L2 信箱详情

点击信箱块进入信件堆叠，展示当前信件、未读、待回信、待寄状态。

L3 堆叠浏览

左右点击、拖拽、键盘方向键切换信件；当前卡点击进入阅读器。

L4 设置/装饰

抽屉面板编辑名称、图标、主题色、材质、装饰元素；删除需二次确认。

  • 重名在提交时校验，错误显示在输入框下方。
  • 最后一个信箱不可删除，按钮置灰并给原因。
  • 20 个以上信箱提示整理归档，但不强制限制。
ED

信件编辑器

文字、图片、录音、计划组件、撤销重做、辅助线。

L1 写信入口

首页新建、信箱详情新建、阅读器回信都进入同一个编辑器。

L2 页面与模板

左侧页面缩略图管理多页信纸，顶部显示保存状态和历史栈。

L3 画布编辑

拖拽元素、双击文字、插入图片/录音/印章，吸附线实时出现。

L4 属性面板

字体、竖排、层级、透明度、裁切、录音气泡、定时寄出都在右侧局部面板。

  • 撤销栈上限 50 步，新增、删除、移动、属性变更都入栈。
  • 录音不支持时隐藏录音入口，显示浏览器兼容提示。
  • 离开页面前如有未保存更改，应用内弹窗先拦截。
RD

信件阅读器

蜡封拆信、分页翻页、语音气泡、回信与同步手账。

L1 来信提醒

首页快速继续、信箱未读角标、离线送达提示都可进入阅读。

L2 选择信件

在堆叠浏览中选中信件，未读信显示蜡封和“新来信”状态。

L3 阅读沉浸

拆信动画完成后显示真实纸张，支持分页、书签、左右翻页。

L4 音频/回信

语音气泡需点击播放，BGM 渐低；回信自动带入原信关联。

  • 自动播放被浏览器拦截时不报错，降级为播放提示按钮。
  • 翻页动效可跳过，reduced-motion 下改为淡入淡出。
  • 书签保存到信件元数据，下次进入直接跳转。
PL

计划组件系统

年度 3-in-1、年/月/周/日下钻、嵌入信纸。

L1 手账入口

顶部导航和底部标签进入手账，显示年度进度与最近记录。

L2 年/月视图

YEAR、NOTE、LIST 三视图切换，月份卡显示任务密度和书签。

L3 日视图编辑

日程、清单、随笔、信件摘要可在同一日页编辑。

L4 信纸嵌入

编辑器插入计划组件后，进入内部编辑模式，退出回到信纸画布。

  • 组件嵌入是引用，不复制数据，手账修改后信纸内同步。
  • 组件宽度小于 200px 时仅显示标题和完成进度。
  • 从信件同步到手账时自动生成当日摘要。
SD

慢递与待寄系统

定时发送、随机慢递、离线加密投递包。

L1 待寄入口

首页统计、信箱详情状态、编辑器定时按钮进入待寄管理。

L2 待寄列表

按投递中、可撤回、即将送达分组，支持预览和撤回。

L3 定时设置

选择具体日期、农历、纪念日快捷项或随机慢递档位。

L4 投递包

生成 .letter 加密文件，导入时输入密码并选择目标信箱。

已写完 可撤回 投递中 已送达
  • 10 分钟撤回窗口结束后只可查看，不可修改。
  • 应用关闭期间到期，下次打开批量补送达并提示。
  • 随机天数生成后固定，不因刷新而变化。
DS

数据安全与备份

自动草稿、全量备份、导入恢复、冲突回滚。

L1 设置入口

全局设置进入数据管理，也可从编辑器保存状态点击查看。

L2 备份中心

显示最近备份、存储占用、IndexedDB 状态和媒体数量。

L3 导出/导入

选择范围、是否包含媒体、是否 AES 加密，导入时预览摘要。

L4 冲突处理

合并、覆盖、重命名导入；失败自动恢复导入前快照。

元数据 媒体 加密 回滚
  • 导出进度超过 1 秒显示进度条，不阻塞页面阅读。
  • 覆盖模式必须二次确认，说明会清空当前数据。
  • 旧版本备份自动执行迁移脚本，失败给可恢复建议。
核心任务 用户动作 系统反馈 异常与恢复
创建信箱

点击新增信箱，填写名称，选择图标/主题/默认信纸。

右侧抽屉保存后收起，新信箱淡入列表首位。

重名、空名、超长均内联提示；最后一个信箱不可删。

写一封信

选择模板，输入正文，插入照片、录音、印章或计划组件。

顶部显示保存中/已保存，画布显示吸附线和选中框。

刷新前提醒；崩溃后下次进入提示恢复草稿。

拆信阅读

在堆叠卡点击当前信件，观看蜡封裂开和翻盖。

进入分页阅读，语音气泡等待用户点击播放。

动画可跳过；音频失败则保留阅读并提示重试。

慢递寄出

在编辑器选择定时、随机慢递或导出投递包。

待寄列表展示撤回窗口、投递中、预计范围。

离线到期下次打开补送达；投递包密码错误可重试。

备份恢复

选择导出范围、媒体、加密；导入时选择合并或覆盖。

显示备份摘要、进度、导入统计和成功提示。

导入失败自动回滚，冲突项可跳过、覆盖或重命名。
