主流程 页面层级 下一步优化 真实信件 设计总览

Design Goal

新增“信箱设置”：自由设计与装饰信箱

当前信箱只像一个列表项或普通卡片。新的设置页把信箱抽象为 Mailbox Unit：侧栏、首页网格、详情页顶部、快速继续卡片都读取同一个装饰单元，让用户设计一次，整个产品内保持一致。

01 整体选中

信箱卡、标题、角标、贴纸、背景纹理一起组成一个可拖动/保存的单元。

02 插槽装饰

装饰不是随便堆元素，而是落到封套、标题牌、邮戳、挂件、贴纸等固定插槽。

03 跨页面同步

保存后自动应用到侧栏、首页卡片、信箱详情页和新建信件默认主题。

数据结构

{
  id: "mailbox-brenuo",
  theme: {
    unitStyle: "old-paper",
    shell: "mailbox-object",
    accent: "#c95f7a",
    texture: "paper-fiber",
    decorations: [
      { slot: "seal", type: "wax", x: 78, y: 22 },
      { slot: "stamp", type: "postal", x: 12, y: 18 },
      { slot: "charm", type: "star", x: 92, y: -8 }
    ]
  }
}

页面同步

  • 首页网格卡片：读取 `unitStyle / accent / decorations`。
  • 侧栏信箱列表：自动生成缩略版 `mini-unit`。
  • 信箱详情页：把主题色、纹理和封面物件应用到拆信舞台。
  • 新建信件：默认继承信箱主题，但允许单封信单独覆盖。

操作逻辑

  1. 点击信箱右上角设置，打开装饰工作台。
  2. 默认选中整体单元，可切换到单个插槽。
  3. 选择材质、布局、贴纸、角标后即时预览。
  4. 保存后写入本地存储，并刷新所有信箱入口。
