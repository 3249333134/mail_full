一款以「书信的温度」为核心的数字书信创作与管理应用，支持多信箱管理、沉浸式编辑阅读、计划组件嵌入与慢递仪式感体验。

一、项目概述

1.1 项目背景

在即时通讯泛滥的时代，书信作为一种慢节奏、高情感浓度的交流方式，正在被重新发现价值。许多用户希望有一个专属的数字空间，用来存放对重要之人的书信、日记和手账，脱离社交平台的喧嚣，回归书写本身的沉静与真诚。

「信笺」定位为一款本地优先的数字书信应用，强调纸质书信的仪式感和叙事气质，同时融合现代生产力工具（计划、手账、待办）的便利性，打造一个兼具情感温度与实用价值的私人数字书信馆。

核心价值主张：不是又一个笔记应用，而是一个「可以写信的地方」——所有功能都服务于「书写、保存、回味书信」这一核心体验。

1.2 产品定位

  • 产品类型：本地优先（Local-first）的 Web 应用，支持离线使用，数据存储于用户本地
  • 目标平台：桌面浏览器（优先）+ 移动端浏览器（响应式适配）
  • 商业模式：纯前端工具，无后端、无账号、无付费墙；用户完全拥有自己的数据
  • 差异化关键词：书信仪式感、纸张质感、多信箱叙事、慢递体验、计划组件嵌入

1.3 设计目标

维度 目标描述 衡量标准
视觉体验 保留信封、纸张、蜡封的叙事气质，避免单一米色疲劳，建立旧相册式的视觉氛围 用户首次进入能感知到「书信感」而非「工具感」
交互效率 三栏编辑器结构清晰，创作流程顺畅，核心操作不超过2次点击 新建一封信并完成基础排版的时间 < 30秒
数据安全 用户对数据有完全掌控感，自动保存、备份、恢复流程清晰可靠 数据丢失风险趋近于零；备份导出成功率 100%
情感体验 拆信、阅读、回信形成完整的情感闭环，慢递机制强化等待的仪式感 用户愿意反复打开回味已有的信件
扩展性 组件化架构，计划、手账、日记等支线功能可插拔，不干扰核心体验 新增功能模块不破坏现有交互流程

1.4 范围与边界

本期包含（In Scope）

  • 多信箱管理与信箱装饰
  • 信件编辑器（文字、图片、语音、组件）
  • 沉浸式信件阅读器（拆信动画、分页、语音气泡）
  • 年/月/周/日/清单计划组件（支持信纸内嵌）
  • 手账系统与日记支线
  • 待寄信件与定时慢递
  • 本地数据备份与恢复
  • 18种真实信件模板
  • 响应式移动端适配

本期不包含（Out of Scope）

  • 云端同步与多端实时协作
  • 用户账号系统
  • 在线信件投递（无后端服务）
  • 多人实时协同编辑
  • AI 辅助写作功能
  • 原生 App 版本

二、用户与场景

2.1 目标用户画像

情感记录者

核心用户 · 占比约 60%
特征
20-35岁，有稳定情感关系，喜欢文字表达，重视仪式感
核心诉求
给爱人/朋友写长信，记录心情与故事，希望有一个私密的、有温度的存放空间
使用频率
每周1-3次，每次15-60分钟
痛点
备忘录太冰冷、社交平台太公开、日记本不方便携带和搜索

IP 创作者 / 同人爱好者

特色用户 · 占比约 25%
特征
剧本杀、小说、游戏爱好者，为喜欢的角色创作书信体内容
核心诉求
按角色/故事线分信箱管理，需要多种信纸风格，支持导出图片分享
使用频率
创作高峰期密集使用，平时偶尔打开回味
痛点
普通文档编辑器没有书信氛围，排版导出麻烦

扩展用户 · 占比约 15%
特征
喜欢手账、计划、复盘，追求生活的秩序感和仪式感
核心诉求

2.2 核心使用场景

场景一：夜晚写信

触发：睡前安静时刻，想给对方写点什么

路径：打开应用 → 选择对应信箱 → 新建信件 → 编辑文字/添加照片/录音 → 保存或定时寄出

情绪：沉静、温柔、专注

场景二：拆信回味

触发：收到提醒/想念对方/随机翻到

路径：打开信箱 → 浏览信件堆叠 → 选择一封 → 观看拆信动画 → 阅读内容/播放语音 → 写回信

情绪：期待、感动、温暖

场景三：年度规划

触发：年初/月末，想做计划和复盘

路径：新建信件 → 插入年度计划组件 → 填写目标与任务 → 保存到「给自己的信」信箱 → 每月打开更新进度

情绪：清晰、有掌控感、期待

场景四：慢递仪式

触发：纪念日/生日/特殊日期前，想写一封给未来的信

路径：写完信 → 设置定时寄出时间 → 信件进入「待寄」状态 → 到期自动「送达」对应信箱 → 收到提醒拆信

情绪：仪式感、期待、时间的重量

3.3 页面层级定义

  • 一级页面：用户进入某功能域的主入口。如信箱总览、手账首页、待寄列表。
  • 二级页面：具体功能区或列表视图。如信箱详情、手账月视图、搜索结果。
  • 三级页面：核心任务执行页面。如编辑器画布、阅读器、组件内部编辑。
  • 四级页面：弹窗、抽屉、设置面板。如信箱设置、元素属性、备份导入、定时发送。
设计原则：核心操作（写信、读信）不超过两级跳转到达；支线功能（手账、日记、设置）收纳在三级及以下，不干扰主路径。

四、详细功能需求

4.1 信箱管理系统

信箱基础管理

模块：信箱
  • MB-001
    信箱创建

    用户可创建多个信箱，每个信箱包含：名称、图标、主题色、描述。创建后自动生成默认信纸样式。

  • MB-002
    信箱编辑与删除

    支持修改信箱名称、图标、主题；删除信箱需二次确认，删除后信件进入回收站（保留7天）或立即彻底删除。

  • MB-003
    信箱排序

    支持拖拽调整信箱顺序，排序状态持久化保存。默认按最近活动时间排序。

  • MB-004
    信箱统计信息

    每个信箱显示：信件总数、未读数、最近一封日期。首页展示全局统计：信箱数、信件总数、待寄数。

信件浏览与筛选

模块：信箱
  • MB-005
    堆叠浏览

    信箱详情页以堆叠卡片形式展示信件，当前居中放大，左右露出前后信件预览。支持左右滑动/点击箭头切换。

  • MB-006
    时间线导航

    底部时间轴显示信件分布，点击可快速跳转到对应月份的信件。

  • MB-007
    筛选与标签

    支持按状态筛选：全部/未读/待回信/有录音/有照片。支持自定义标签，信件可打多个标签。

  • MB-008
    信件详情面板

    右侧固定面板显示当前信件元信息：收信人、日期、状态、所属信箱，以及阅读/编辑/导出/回信操作。

信箱装饰系统

模块：信箱 · P2
  • MB-009
    材质主题

    四种基础材质：铜制邮筒、木质信盒、牛皮档案袋、航空信封。每个材质对应不同的视觉表现和装饰元素。

  • MB-010
    装饰元素组合

    可选装饰：蜡封章、手写标签、邮戳、照片夹、捆扎绳。用户可自由组合，形成个性化信箱外观。

  • MB-011
    状态可视化

    未读信件通过信箱插旗、数字角标等方式呈现，保持整体美感的同时传递状态信息。

4.2 信件编辑器

三栏布局结构

模块：编辑器
  • ED-001
    左侧工具轨（Tool Rail）

    包含：页面缩略图（新增/切换/删除页面）、基础工具（文字/图片/语音/视频/贴图/组件）、组件库（日期/收信人/地点/年计划/月计划等）。

  • ED-002
    中间画布区（Canvas Zone）

    信纸画布居中展示，顶部工具栏显示当前信纸样式和缩放控制（百分比/适应宽度）。画布支持拖拽移动元素、缩放。

  • ED-003
    右侧属性面板（Property Dock）

    分段式：信纸/封面切换。选中元素时显示对应属性：文字属性（字体/字号/行距/颜色）、图片属性、组件属性、层级与对齐操作。

  • ED-004
    顶部操作栏

    返回按钮、信件标题与保存状态指示、撤销/重做、预览、保存按钮。自动保存状态实时可见。

编辑基础能力

模块：编辑器 · P0
  • ED-005
    文字编辑

    支持横排/竖排切换、字体选择（宋体/楷体/毛笔/钢笔等多套字体栈）、字号、行距、字色。双击文字进入编辑态。

  • ED-006
    图片插入

    支持本地上传图片，可拖拽调整位置和尺寸，支持圆角、透明度调节。图片随信件数据一同存储。

  • ED-007
    语音录制

    调用麦克风录音，支持录制/暂停/重听/删除。录音文件随信件保存，阅读时通过语音气泡播放。

  • ED-008
    多页支持

    一封信可包含多页信纸，左侧页面缩略图切换，支持新增/删除/拖拽排序页面。

编辑辅助功能

模块：编辑器 · P0
  • ED-009
    撤销/重做栈

    50步操作历史，所有新增/删除/移动/属性修改均入栈。快捷键 Ctrl+Z / Ctrl+Y。操作栈随草稿一同保存。

  • ED-010
    层级管理

    支持置顶、置底、上移一层、下移一层。右键菜单和属性面板双通道操作。图层面板显示当前页所有元素。

  • ED-011
    辅助线与吸附

    拖拽元素时显示水平/垂直中心线、边距参考线。距离小于8px时自动吸附对齐。

  • ED-012
    对齐操作

    属性面板提供：左对齐、水平居中、右对齐、顶部对齐、垂直居中、底部对齐。支持多元素选中后批量对齐。

组件嵌入与真实模板

模块：编辑器 · P1/P3
  • ED-013
    计划组件插入

    从左侧组件库拖拽年/月/周/日/清单组件到信纸，可自由调整位置和尺寸。双击进入组件内部编辑模式。

  • ED-014
    组件透明背景

    一键切换组件是否显示背景，透明模式下组件融入信纸不突兀。

  • ED-015
    真实信件模板应用

    18种模板（竹简/奏折/花笺/侨批/航空邮简等）一键应用，自动切换文字方向、字体栈、纸张材质。

  • ED-016
    模板参数调节

    可微调纸张年代感、污渍程度、折痕深浅，生成个性化的真实感效果。

4.3 信件阅读器

拆信动画流程

模块：阅读器 · P1
  • RD-001
    蜡封裂开

    点击信封后，蜡封先出现裂纹（0.2s），随后分两半向两侧滑落，带轻微弹跳效果。

  • RD-002
    信封翻盖

    上盖向上翻开（约0.3s），伴随纸张轻响音效（用户首次交互后才播放）。

  • RD-003
    信纸抽出

    信纸从信封中缓缓滑出（0.4s），背景同时柔和变暗聚焦内容。抽出后进入阅读态。

  • RD-004
    动画跳过机制

    同一封信第二次及以后打开，自动跳过拆信动画直接进入阅读。设置中可强制开启。

阅读体验

模块：阅读器
  • RD-005
    分页翻页

    多页信件支持左右翻页，带纸张翻动的卷曲效果。支持键盘左右键、点击两侧区域、滑动手势三种操作。

  • RD-006
    进度与页码

    底部显示当前页码/总页数，以及进度条。点击进度条可跳转到对应页。

  • RD-007
    书签功能

    长按段落可添加书签，书签列表显示在侧边。下次打开自动定位到上次阅读位置。

  • RD-008
    语音气泡交互

    拆信完成后，语音气泡从右下角淡入。用户点击才播放（规避自动播放限制）。本会话已授权后可自动淡入。

  • RD-009
    BGM混音逻辑

    语音播放时，BGM自动降至15%音量；语音结束后BGM淡回原音量。过渡平滑，无突兀感。

阅读操作

模块：阅读器
  • RD-010
    底部操作栏

    固定底部：编辑、导出长图、回信、更多（删除/移动信箱/标签）。桌面端右侧面板同步显示。

  • RD-011
    回信功能

    点击回信跳转到编辑器，自动填充收信人（反转）、引用原信可选、继承当前信箱。

  • RD-012
    导出图片

    支持导出单页或全页为PNG长图，分辨率可选。导出时完整保留纸张材质、印章等效果。

  • RD-013
    故事线入口

    侧边栏显示关联的日记章节、手账记录快捷入口，点击跳转到对应支线内容。

4.4 计划组件系统

年度计划 3-in-1

模块：计划 · P1
  • PL-001
    YEAR 年度总览

    12个月色块展示，按季度分组。每个月可标记多个类别（日常/工作/成长/重点），颜色区分。点击月份进入月计划。

  • PL-002
    NOTE 自由笔记

    年度目标、季度复盘、关键事件等自由书写区域，支持富文本格式。

  • PL-003
    LIST 清单页

五、视觉设计规范

5.1 色彩系统

主色板

深墨色 #1a1d25 · 主文本/主操作
玫瑰色 #c96567 · 强调/叙事/蜡封
叶绿色 #4a7c59 · 支线功能/成功态
暖金色 #b8956a · 警告/装饰/邮戳

中性色板

纸张暖白 #faf6f0 · 页面背景
奶油米 #f5efe4 · 卡片/次级背景
次级灰 #5a6278 · 次要文本
夜色深蓝 #2a334a · 深色主题/夜间信箱
用色原则：大面积使用低饱和度的纸张色系，小面积使用玫瑰色作为情感强调。功能操作优先用深墨色，避免彩色按钮过多造成视觉噪音。

5.2 字体与排版

  • UI 字体栈：-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", sans-serif（界面文字）
  • 书信宋体："Songti SC", "SimSun", "Noto Serif SC", serif（正式书信正文）
  • 毛笔行楷："STXingkai", "华文行楷", "KaiTi", "楷体"（毛笔/竖排书信模板）
  • 钢笔手写："FZKai-Z03S", "Kaiti SC", "HanziPen SC"（钢笔信模板）
  • 打字机："Courier New", Courier, monospace（电报/打字机模板）

字号层级

层级字号字重用途
大标题 H128-36px600页面主标题
小标题 H220-24px600模块标题、卡片标题
正文 Body14-15px400正文、描述文字
小字 Small12-13px400辅助信息、时间戳、标签
书信正文16-18px400信纸内文字（行高1.8）

5.3 材质与阴影

  • 纸张材质：通过多层 CSS 背景叠加实现纸纹、纤维、泛黄效果，不依赖图片资源
  • 折痕效果：使用线性渐变模拟折痕的高光与阴影，十字折痕为两条交叉线
  • 卡片阴影：双层阴影结构（近景淡 + 远景散），模拟纸张悬浮在桌面上的真实感
  • 圆角规范：卡片 8-12px，按钮 6-8px，避免过度圆润失去纸质感
  • 投影方向：统一光源来自左上方，阴影偏右下，Y轴偏移为主

5.4 组件规范

  • 主按钮：深墨色填充 + 白色文字 + 8px 圆角，悬停轻微提亮
  • 次按钮：透明背景 + 细边框 + 深墨色文字
  • 幽灵按钮：无边框纯文字，hover 出现浅底色
  • 输入框：1px 边框 + 8px 圆角 + 浅灰底色，focus 时边框变玫瑰色
  • 卡片：白底 + 轻阴影 + 细边框，内容区内边距统一 20-24px

六、交互设计规范

6.1 动效原则

  • 节奏：慢而从容：动效时长偏长（0.3-0.5s），缓动函数优先 ease-out，营造沉静不急躁的氛围
  • 层级：物理感：元素出现有先后顺序，模拟真实物体的运动惯性，不做机械的同时出现
  • 反馈：轻而明确：点击、悬停有细微反馈（颜色变化/轻微位移），但不过度夸张
  • 转场：叙事性：拆信、翻页等核心动效带有故事感，不是单纯的位移淡入

动效时长参考

动效类型时长缓动说明
按钮/状态反馈150-200msease-out快速响应，不拖沓
面板展开/收起250-300msease-out流畅但不迟缓
页面切换300-400msease-in-out有明显过渡感
拆信动画800-1200mscubic-bezier仪式感动效，分阶段
翻页动效400msease-in-out模拟纸张翻动

6.2 核心交互流

写信流程（主路径）

  1. 首页 → 点击「新建信件」或选择信箱后新建
  2. 进入编辑器，默认信纸样式，光标自动聚焦文字区
  3. 输入正文 → 可插入图片、录音、组件
  4. 自动保存持续进行中，顶部状态可见
  5. 完成后点击「保存」或直接返回（自动保存）
  6. 可选：设置定时寄出 / 导出图片

读信流程

  1. 信箱详情 → 点击目标信件
  2. 触发拆信动画（首次观看，后续可跳过）
  3. 进入阅读器，语音气泡从右下浮出（如有录音）
  4. 翻页阅读 → 可添加书签
  5. 底部操作：回信 / 编辑 / 导出 / 更多

6.3 移动端适配

  • 断点：768px 以下切换为移动端布局
  • 导航：侧边栏收起为底部 Tab 栏（信箱、写信、手账、我的）
  • 编辑器：全屏画布 + 底部工具栏 + 属性从底部上滑弹出
  • 阅读器：全屏沉浸阅读，操作按钮收到底部
  • 手势：左右滑翻页、双指缩放画布、长按出菜单、下拉刷新
  • 触控目标：按钮最小尺寸 44×44px，间距不小于 8px

七、非功能需求

7.1 性能要求

指标要求说明
首屏加载 < 2s（常规网络） 静态资源压缩 + Service Worker 缓存
编辑器帧率 ≥ 55fps 拖拽时 使用 rAF 节流，避免布局抖动
信件加载 < 500ms 打开一封信 常规 2-3 页带图片的信件
导出图片 < 3s（单页信纸） 含材质层和元素的完整渲染
数据量支持 至少 500 封信流畅运行 列表使用虚拟滚动优化

7.2 兼容性

  • 桌面浏览器：Chrome 90+、Edge 90+、Safari 14+、Firefox 88+
  • 移动浏览器：iOS Safari 14+、Chrome Mobile 90+
  • API 兼容降级：
    • IndexedDB 不可用时降级到 localStorage（提示容量限制）
    • MediaRecorder 不支持时隐藏录音功能并提示
    • 自动播放被拦截时优雅降级为点击播放
  • 分辨率：最小支持宽度 320px，最大自适应 2560px

7.3 数据安全

  • 本地优先：所有数据默认存储在用户本地浏览器，不上传任何服务器
  • 加密备份：可选密码加密备份文件，使用 AES-256 算法
  • 无账号系统：不收集用户身份信息，不设置注册登录流程
  • 数据隔离：不同浏览器实例数据独立，不跨域共享
  • 导出文件：用户手动导出的文件完全由用户掌控，应用不留存副本

7.4 可用性

  • 键盘支持：常用操作支持快捷键（撤销/重做/保存/新建等）
  • 无障碍：语义化 HTML 结构，图片有 alt 文本，颜色对比度满足 WCAG AA
  • 错误处理：存储失败、录音失败、导入失败均有友好提示和恢复建议
  • 空状态：无信箱、无信件、无搜索结果等空场景有引导性设计
